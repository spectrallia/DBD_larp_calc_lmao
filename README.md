# DBD_larp_calc_lmao

ENG:
A Dead by daylight perk build calculator (both for killers and survivors). will display prices in Auric cells and Iridescent Shards. This was made as a school project and will not be updated whatsoever. Expect low quality and bugs

Made for DBD version: 9.6.x
